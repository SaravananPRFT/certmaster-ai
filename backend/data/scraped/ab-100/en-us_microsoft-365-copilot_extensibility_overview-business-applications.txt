For custom agents, you can add tools and knowledge directly to the agent.
For Microsoft 365 Copilot, you don't extend functionality directly with tools and knowledge. Instead, you extend Microsoft 365 Copilot with a
built in Copilot Studio. A declarative agent is an agent intended to be run within the Microsoft 365 Copilot experience. The agent has its own specialized instructions and purpose, and you can add tools and knowledge to it. You can bring tools and knowledge into Microsoft 365 Copilot in a three step process:
Create a new declarative agent.
Add tools and knowledge to the agent.
Publish the agent and make it available to Microsoft 365 Copilot.
