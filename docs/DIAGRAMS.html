RAG Retrieval Pipeline

How Azure AI Search retrieves relevant documentation chunks for each question.

flowchart LR subgraph INPUT["Input"] Q["Query text\n'AI-102 Generative AI\nHard question'"] EXAM["exam_code = AI-102\nobjective = Implement\nGenerative AI Solutions"] end subgraph EMBED_STEP["Step 1 — Embed"] E["Azure OpenAI\ntext-embedding-3-large\n→ 3072-dim vector"] end subgraph SEARCH["Step 2 — Search Azure AI Search"] direction TB FILT["OData Filter\nexam_code eq 'AI-102'\nAND objective eq 'Implement...'"] KW["BM25 Keyword Search\nfull-text on content field"] VEC["Vector Search\nHNSW on content_vector\nk_nearest_neighbors = 5"] SEM["Azure Semantic Ranker\nL2 reranking\non merged results"] FILT --> KW FILT --> VEC KW --> SEM VEC --> SEM end subgraph RESULT["Step 3 — Build Context"] SORT["Sort by relevance score\n(descending)"] TRUNC["Token-budget truncation\nMax 4096 tokens\n~1.3 tokens per word"] FORMAT["Format each chunk:\nSOURCE: title url\ncontent text"] SORT --> TRUNC --> FORMAT end subgraph FALLBACK["⚠️ Fallback"] FB["If ANY exception occurs\nreturn 1 hardcoded chunk\ndoc-id: fallback-001"] end Q --> E EXAM --> FILT E --> VEC Q --> KW SEARCH -->|"Top 5 chunks"| RESULT SEARCH -->|"Exception"| FALLBACK RESULT --> OUT(["Context string + doc_ids\nto prompt builder"]) FALLBACK --> OUT style OUT fill:#22c55e,stroke:#22c55e,color:#fff style FALLBACK fill:#78350f,stroke:#f59e0b,color:#fbbf24
BM25 keyword: finds exact term matches
HNSW vector: finds semantically similar content
Semantic ranker: re-scores combined results by relevance
Fallback: used when Azure AI Search is unavailable
